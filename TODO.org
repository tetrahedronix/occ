* Project Overview
  =occ= generates reproducible container sandboxes for AI coding agents based on a declarative =orchestrator.yml=.
  Produces a ready-to-use =Dockerfile= and a standalone shell launcher without runtime dependencies on =occ=.

* Technical Architecture
  - *Language:* Go
  - *YAML Parser:* =gopkg.in/yaml.v3=
  - *Templating Engine:* Go standard library =text/template=
  - *Embedded Templates:* Go =embed= package for default templates
  - *Container Runtime:* declared per-project in =orchestrator.yml= (=podman= or =docker=); templates branch on this field rather than assuming one engine
  - *Package Manager Mapping:* distro selection drives package-manager syntax (=apt-get=, =apk=, ...) inside the templates; distro support is scoped explicitly, not implied by the base-image name alone
  - *Provenance:* every generated file carries a header comment with the =occ= version and a hash of the source =orchestrator.yml=, to detect stale/hand-edited output later
